# 📝 To-Do List App
A simple, lightweight To-Do List application built with HTML, CSS, and JavaScript. This project allows users to add, complete, and delete tasks in an intuitive and responsive interface — perfect for organizing daily activities and staying productive.

🚀 Features
- Add new tasks with ease

- Mark tasks as completed

- Remove tasks when done

- Clean and minimalist design

- Fully responsive layout – works great on all screen sizes

- Built with JavaScript (no frameworks)
